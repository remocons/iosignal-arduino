# Remocon8266 scanner (주변 장치 목록과 세부 정보)

Remocon8266 보드가 앱처럼 #search를 보내 같은 공유기의 장치를 찾고, 이름 목록을 OLED에 보여 줍니다. 버튼으로 목록을 움직여 고르면 그 장치의 CID, 이름, 분류, 타입(또는 버튼 목록), 상태를 보여 주고 상태가 바뀌면 바로 갱신합니다.

## 준비물

- 보드: Remocon8266 보드 (D1 mini 기반) (폴더의 회로도 PDF 참고)
- 네트워크: Wi-Fi 2.4GHz 공유기
- 앱: https://remocon.kr 장치 카드의 scan 버튼으로 다시 찾습니다
- 연동: 같은 공유기의 IOSignal 장치: #search에 #notify로 답하는 장치(다른 예제 보드, bayo.tv 등)가 목록에 나옵니다

## 배선

| 보드 핀 | 연결 | 비고 |
| --- | --- | --- |
| GPIO16 (D0) | SW1 위: 목록 위로 / 이전 장치 | 외부 풀업 |
| GPIO0 (D3) | SW2 왼쪽: 다시 찾기 / 목록으로 | 내부 풀업 |
| GPIO14 (D5) | SW3 아래: 목록 아래로 / 다음 장치 | 내부 풀업 |
| GPIO13 (D7) | SW4 오른쪽: 세부 정보 열기 | 내부 풀업 |
| GPIO4, GPIO5 | SSD1306 OLED (SDA, SCL) | I2C |

## 사용 순서

1. Wi-Fi는 업로드한 뒤 USB로 연결해 https://arduino.iosignal.net/wifi/ (보드 설정)에서 넣습니다(데스크톱 Chrome·Edge, 보드가 저장). 같은 페이지에서 다른 IOSignal 서버(호스트:포트), 장치 키와 보드 설정도 넣을 수 있습니다. 스케치의 Wi-Fi 값에 실제 값을 쓰면 그 값이 부팅할 때마다 우선합니다.
2. 같은 공유기에서 다른 예제 보드나 bayo.tv, remocon.kr 장치를 켜 둡니다.
3. 스케치를 업로드합니다. 접속하면 'Searching...' 뒤에 찾은 장치의 이름이 목록으로 나옵니다(한 화면에 3개).
4. SW1·SW3으로 고르고 SW4로 엽니다. CID, 이름, 분류(cat), 타입(ui), 상태(st)가 나옵니다. 열린 동안 상태가 바뀌면 바로 갱신됩니다.
5. 세부 화면에서 SW1·SW3은 이전·다음 장치, SW2는 목록으로 돌아갑니다. 목록에서 SW2는 다시 찾습니다.

## 시그널 절차

| 보내는 쪽 | 받는 쪽 | 태그 | 값 | 설명 |
| --- | --- | --- | --- | --- |
| 장치 | 서버 | `#notify` | `구독` | 검색에 답하는 장치들의 CID를 받습니다. |
| 장치 | 같은 공유기의 장치 | `#search` |  | 접속할 때와 SW2(다시 찾기), 앱 카드의 scan 버튼에서 보냅니다. |
| 다른 장치 | 장치 | `#notify` | `<cid>` | 검색에 자기 CID로 답합니다. 최대 16대까지 목록에 넣습니다. |
| 장치 | 서버 | `<cid>@$name, $ui` | `구독` | 서버에 보관된 이름(이름:분류)과 화면 정보(t=타입 또는 버튼 목록)를 바로 받습니다. |
| 장치 | 서버 | `<cid>@$state` | `구독` | 세부 화면을 연 장치만 구독합니다. 닫으면 구독을 풉니다. |
| 서버 | 장치 | `<cid>@$state` | `close` | 장치가 끊기면 목록에 x로 표시합니다. |
| 장치 | 서버 | `@$name` | `Remocon8266 Scanner:HOME` | 이 보드의 이름과 분류입니다. |
| 장치 | 서버 | `@$ui` | `scan` | 앱 카드의 버튼입니다. 누르면 다시 찾습니다. |
| 장치 | 서버 | `@$state` | `devices=3;open=<cid>` | 찾은 장치 수와 열어 본 장치입니다. |

## 참고

- #search는 같은 공인 IP(같은 공유기)에만 전달됩니다. 앱(remocon.kr)이 장치를 찾는 방식과 같습니다.
- 타입은 $ui의 t= 값(예: switch3.1), p=1이면 own panel, 버튼 목록이면 btn 뒤에 목록을 보여 줍니다.
- 값이 두 개 이상인 상태(bayo.tv 등)는 첫 값만 보여 줍니다.
- 이름은 u8g2의 unifont 한글 폰트(16px)로 그립니다. 다시 찾기는 모든 구독을 풀고 처음부터 찾습니다.
- 2026-11-17 Remocon8266 보드에서 확인: 접속과 scan 명령에서 #search, 같은 공유기의 bayo.tv와 시험 장치 4대(한글 이름)를 찾아 목록에 표시, SW1~SW4로 이동·열기·뒤로, 세부 화면의 CID·이름·분류·타입·상태(사용자가 OLED로 확인).
