# ESP-01 버튼 제어기

ESP-01의 GPIO2 버튼 하나로 다른 장치(4채널 릴레이, ESP-01 릴레이, iris, Remocon8266, 그룹 채널)를 제어합니다. 다른 핀은 쓰지 않아 시리얼이 늘 켜져 있습니다. 대상과 버튼 동작은 보드 설정(target, b1)이라 펌웨어를 고치지 않고 바꿉니다.

## 준비물

- 보드: ESP-01 (ESP8266)
- 네트워크: Wi-Fi 2.4GHz 공유기
- 앱: https://remocon.kr (제어기 카드의 b1 버튼), 대상 장치
- 연동: esp8266-relay4ch
- 연동: esp01-relay-button
- 연동: iris-basic
- 연동: Remocon8266-basic

## 배선

| 보드 핀 | 연결 | 비고 |
| --- | --- | --- |
| GPIO2 | 푸시 버튼 → GND | 내부 풀업. 부팅 때 HIGH여야 하는 핀이라 전원을 켜거나 리셋할 때 누르고 있으면 부팅하지 않습니다. ESP-01에서는 비어 있는 핀입니다(ESP-01S는 파란 LED가 GPIO2에 있음). |
| TX(GPIO1), RX(GPIO3) | USB-TTL 어댑터 | 시리얼 로그와 보드 설정 페이지. 늘 켜져 있습니다. |

## 사용 순서

1. 제어할 장치(예: esp8266-relay4ch, esp01-relay-button, iris-basic, Remocon8266-basic)를 먼저 켜고 CID를 확인합니다.
2. GPIO2와 GND 사이에 버튼을 답니다. 업로드 어댑터로 스케치를 올립니다.
3. USB-TTL을 연결한 채 https://arduino.iosignal.net/wifi/ 에서 Wi-Fi를 넣고, 같은 페이지의 스케치 설정 target에 대상 CID를 넣습니다. 원하면 b1, 서버, 장치 키도 넣습니다. 시리얼이 늘 켜져 있어 언제든 다시 바꿀 수 있습니다.
4. 버튼을 누르면 대상에 명령을 보냅니다. b1을 비워 두면 대상 채널이 하나라도 켜져 있으면 모두 끄고 아니면 모두 켭니다. 's1'(채널 1 토글), 'r2=1'(릴레이 2 켜기), 'all=0'(모두 끄기), 'lamp1:toggle'(다른 장치), '#lab:s2'(그룹 채널)처럼 바꿀 수 있습니다.
5. remocon.kr 카드나 remocon pub "<제어기 cid>@" "target=<cid>" 로 원격으로도 바꿉니다.

## 시그널 절차

| 보내는 쪽 | 받는 쪽 | 태그 | 값 | 설명 |
| --- | --- | --- | --- | --- |
| 장치 | 서버 | `@$name` | `ESP01 Button:HOME` | 이름과 분류(첫 : 뒤)입니다. 서버에 보관됩니다. 분류는 앱이 장치를 묶어 보여 주는 탭 이름입니다. 이름과 분류 모두 보드 설정 name(이름:분류)으로 바꿉니다(바꾸면 바로 다시 보냄). 분류가 없으면 앱의 미분류 탭에 나옵니다. |
| 장치 | 서버 | `@$ui` | `b1` | 버튼 목록입니다. 앱은 누른 버튼 이름을 그대로 명령으로 보냅니다. 서버에 보관됩니다. |
| 장치 | 서버 | `<대상>@$state` | `구독` | 대상(과 b1이 따로 지정한 장치나 그룹)의 상태를 구독합니다. 토글은 마지막 상태의 반대를 보냅니다. |
| 장치 | 대상 | `<대상>@` | `all=1` | 버튼을 누르면 설정대로 보냅니다. 기본은 all=1/all=0, 's1'이면 s1=1처럼 채널 하나입니다. 상태를 받기 전에는 토글을 보내지 않습니다. |
| 대상 | 장치 | `<대상>@$state` | `r1=1;r2=1;r3=1;r4=1` | 대상이 바뀐 상태로 답합니다. 제어기는 자기 $state의 on으로 대상의 켜짐을 알립니다. |
| 앱 | 장치 | `<cid>@` | `b1 / b1=s2 / target=?k3vd` | 누르기, 버튼 설정 바꾸기, 대상 바꾸기. 처리 뒤 상태로 답합니다. |
| 장치 | 서버 | `@$state` | `target=?k3vd;link=1;on=1;b1=` | link는 대상 상태를 알고 있는지, on은 대상의 켜짐(b1이 채널 하나면 그 채널, 기본이나 all이면 하나라도)입니다. 잘못된 설정은 ?로 보입니다. |

## 참고

- ESP-01에서 비어 있는 GPIO2 하나만 버튼으로 씁니다. GPIO0, TX(GPIO1), RX(GPIO3)는 쓰지 않아 시리얼 로그와 USB 보드 설정이 늘 됩니다. 설정 모드는 없습니다.
- GPIO0과 GPIO2는 부팅 때 HIGH여야 합니다. 내부 풀업이 GPIO2를 HIGH로 두므로 평소에는 문제가 없지만, 버튼을 누른 채 켜거나 리셋하면 부팅하지 않습니다.
- ESP-01S는 파란 LED가 GPIO2에 붙어 있어 버튼을 누를 때 LED가 켜질 수 있습니다. 시험하지 않았습니다.
- 2026-11-27 버튼을 GPIO3에서 GPIO2로 옮기고 LED와 설정 모드를 뺐습니다. GPIO3 버튼 하나만 쓰는 예제는 esp01-worynim-button입니다. 2026-11-16 GPIO3 버전은 ESP-01에서 확인했지만 GPIO2 버전은 아직 실물로 확인하지 않았습니다.
- 버튼 동작 형식은 IOSignal 라이브러리의 IOSignalBinding.h 맨 위에 있습니다.
