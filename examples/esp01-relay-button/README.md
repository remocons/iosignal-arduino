# ESP-01 릴레이와 버튼

ESP-01로 릴레이 하나를 1채널 릴레이(relay1.1)로 제어합니다. 버튼으로도 켜고 끕니다.

## 준비물

- 보드: ESP-01 (ESP8266)
- 네트워크: Wi-Fi 2.4GHz 공유기
- 앱: https://remocon.kr 또는 IOSignal Desktop 장치 제어 화면

## 배선

| 보드 핀 | 연결 | 비고 |
| --- | --- | --- |
| GPIO0 | 릴레이 입력 | LOW에서 켜지는 모듈(스케치 기본). 부팅할 때 HIGH(꺼짐)여야 합니다 |
| GPIO2 | 푸시 버튼, 다른 쪽은 GND | 부팅 시 HIGH여야 합니다 |
| TX(GPIO1), RX(GPIO3) | USB-TTL | 로그와 보드 설정 페이지. 늘 시리얼입니다 |

## 사용 순서

1. 업로드 어댑터(USB-TTL)로 스케치를 올립니다.
2. 같은 어댑터로 https://arduino.iosignal.net/wifi/ 에서 Wi-Fi를 넣습니다(원하면 서버, 장치 키, 보드 설정 name도). 시리얼이 늘 켜져 있어 언제 연결해도 응답합니다. 스케치의 Wi-Fi 값에 실제 값을 써도 됩니다.
3. 릴레이와 버튼을 연결하고 전원을 다시 넣습니다.
4. 같은 공유기에 연결한 브라우저로 https://remocon.kr 을 엽니다.
5. ESP01-Relay-Btn 카드의 릴레이 스위치를 누르거나 보드의 버튼을 누릅니다.

## 시그널 절차

| 보내는 쪽 | 받는 쪽 | 태그 | 값 | 설명 |
| --- | --- | --- | --- | --- |
| 장치 | 서버 | `#search` | `구독` | 앱의 검색 요청을 받도록 구독합니다. |
| 장치 | 서버 | `@$name` | `ESP01-Relay-Btn:HOME` | 이름과 분류(첫 : 뒤)입니다. 서버에 보관됩니다. 분류는 앱이 장치를 묶어 보여 주는 탭 이름입니다. 이름과 분류 모두 보드 설정 name(이름:분류)으로 바꿉니다(바꾸면 바로 다시 보냄). 분류가 없으면 앱의 미분류 탭에 나옵니다. |
| 장치 | 서버 | `@$ui` | `t=relay1.1;b=r1=1,r1=0` | 공식 타입 relay1.1입니다(확장형: 첫 키가 t). 앱이 그 타입의 화면(릴레이 스위치 하나)을 그립니다. 이 타입을 모르는 예전 앱에는 b의 켜기·끄기 버튼이 나옵니다. 서버에 보관됩니다. |
| 장치 | 서버 | `@$state` | `r1=0` | 현재 상태입니다. 서버에 보관됩니다. |
| 장치 | 앱 | `#notify` | `<cid>` | 접속했음을 알립니다. |
| 앱 | 장치 | `#search` |  | 앱이 시작할 때, 1초 뒤, 이후 15초마다 보냅니다. |
| 장치 | 앱 | `#notify` | `<cid>` | 검색에 자기 CID로 답합니다. |
| 앱 | 서버 | `<cid>@$name, $ui, $state` | `구독` | 보관된 이름, 버튼(타입), 상태를 바로 받아 카드를 만듭니다. |
| 앱 | 장치 | `<cid>@` | `r1=1` | 앱의 스위치가 값을 지정하는 명령을 보냅니다. 장치가 받는 태그는 @입니다. |
| 장치 | 앱 | `@$state` | `r1=0` | 명령을 처리한 뒤, 그리고 보드의 버튼으로 바꿀 때 상태를 보냅니다. 앱의 대기 표시가 풀립니다. |
| 서버 | 앱 | `<cid>@$state` | `close` | 장치가 끊기면 서버가 보내고 카드가 사라집니다. |

## 참고

- GPIO0과 GPIO2를 LOW로 누른 채 전원을 넣으면 부팅되지 않습니다.
- r1=1·r1=0과 all=1·all=0(채널 키 규칙)을 받습니다. 상태 묻기 ?와 모르는 명령에도 상태를 보냅니다. 버튼 제어기(esp01-button-controller 등)의 기본 동작(채널 토글, all)이 그대로 맞습니다.
- HIGH에서 켜지는 릴레이 모듈이면 스케치의 RELAY_ACTIVE_LOW를 false로 바꿉니다. 그런 모듈은 부팅 순간(GPIO0 HIGH) 릴레이가 잠깐 붙을 수 있습니다.
- GPIO가 아니라 시리얼 명령으로 릴레이를 켜는 모듈(예: LC Technology ESP-01 릴레이 v1.0)은 이 예제로 동작하지 않습니다.
- ESP-01S 안내: 핀 배치가 ESP-01과 같아 같은 스케치를 쓸 수 있습니다. 파란 LED가 GPIO2에 있어 버튼을 누르는 동안 켜집니다. 공식 지원 보드는 아니며 시험하지 않았습니다.
- 2026-11-27 switch2.1(릴레이+LED)에서 relay1.1로 바꾸고 LED와 설정 모드(켠 뒤 3초 버튼, RX 감시)를 없앴습니다. 실제 보드로는 아직 확인하지 않았습니다(draft).
