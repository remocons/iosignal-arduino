# ESP-01 릴레이와 버튼

ESP-01로 릴레이와 LED를 2구 스위치로 제어합니다. 버튼으로도 릴레이를 켜고 끕니다.

## 준비물

- 보드: ESP-01 (ESP8266)
- 네트워크: Wi-Fi 2.4GHz 공유기
- 앱: https://remocon.kr 또는 IOSignal Desktop 장치 제어 화면

## 배선

| 보드 핀 | 연결 | 비고 |
| --- | --- | --- |
| GPIO0 | 릴레이 입력 | active low. 부팅할 때 HIGH(꺼짐)여야 합니다 |
| GPIO1 (TX) | LED | active low. 시리얼과 함께 쓸 수 없습니다 |
| GPIO2 | 푸시 버튼, 다른 쪽은 GND | 부팅 시 HIGH여야 합니다 |

## 사용 순서

1. Wi-Fi는 업로드한 뒤 USB-TTL로 https://arduino.iosignal.net/wifi/ 에서 넣습니다(원하면 서버, 장치 키와 보드 설정도). 저장된 Wi-Fi가 없거나, 설정 페이지가 RX(GPIO3)로 요청을 보내거나, 켠 뒤 3초 안에 버튼을 누르고 있으면 다음 리셋까지 GPIO1이 LED 대신 시리얼(TX)이 됩니다. 다른 스케치가 저장한 Wi-Fi가 남아 있어도 연결 후 몇 초 안에 페이지에 응답합니다. 스케치의 Wi-Fi 값에 실제 값을 써도 됩니다.
2. 업로드 어댑터로 스케치를 올립니다.
3. 릴레이와 버튼을 연결하고 전원을 다시 넣습니다.
4. 같은 공유기에 연결한 브라우저로 https://remocon.kr 을 엽니다.
5. ESP01-Relay-Btn 카드의 1번(릴레이), 2번(LED) 스위치를 누릅니다.

## 시그널 절차

| 보내는 쪽 | 받는 쪽 | 태그 | 값 | 설명 |
| --- | --- | --- | --- | --- |
| 장치 | 서버 | `#search` | `구독` | 앱의 검색 요청을 받도록 구독합니다. |
| 장치 | 서버 | `@$name` | `ESP01-Relay-Btn:HOME` | 이름과 분류(첫 : 뒤)입니다. 서버에 보관됩니다. 분류는 앱이 장치를 묶어 보여 주는 탭 이름입니다. 이름과 분류 모두 보드 설정 name(이름:분류)으로 바꿉니다(바꾸면 바로 다시 보냄). 분류가 없으면 앱의 미분류 탭에 나옵니다. |
| 장치 | 서버 | `@$ui` | `t=switch2.1` | 공식 타입 switch2.1입니다(확장형: 첫 키가 t). 앱이 그 타입의 화면을 그립니다. 서버에 보관됩니다. |
| 장치 | 서버 | `@$state` | `s1=0;s2=0` | 현재 상태입니다. 서버에 보관됩니다. |
| 장치 | 앱 | `#notify` | `<cid>` | 접속했음을 알립니다. |
| 앱 | 장치 | `#search` |  | 앱이 시작할 때, 1초 뒤, 이후 15초마다 보냅니다. |
| 장치 | 앱 | `#notify` | `<cid>` | 검색에 자기 CID로 답합니다. |
| 앱 | 서버 | `<cid>@$name, $ui, $state` | `구독` | 보관된 이름, 버튼(타입), 상태를 바로 받아 카드를 만듭니다. |
| 앱 | 장치 | `<cid>@` | `s1=0` | 앱의 스위치가 값을 지정하는 명령을 보냅니다. 장치가 받는 태그는 @입니다. |
| 장치 | 앱 | `@$state` | `s1=0;s2=0` | 명령을 처리한 뒤 상태를 보냅니다. 앱의 대기 표시가 풀립니다. |
| 서버 | 앱 | `<cid>@$state` | `close` | 장치가 끊기면 서버가 보내고 카드가 사라집니다. |

## 참고

- GPIO0과 GPIO2를 LOW로 누른 채 전원을 넣으면 부팅되지 않습니다.
- GPIO1을 LED로 써서 설정 모드가 아니면 시리얼 출력을 쓸 수 없습니다. RX(GPIO3)는 늘 읽어서 설정 페이지의 요청("IMPROV" 헤더)이 오면 설정 모드로 바뀝니다.
- 2026-11-17 ESP-01(Wi-Fi 저장됨)에서 확인: 일반 부팅 후 첫 Improv 요청에 설정 모드로 바뀌고 다음 요청부터 상태와 보드 설정 목록에 응답했습니다.
- s1은 릴레이, s2는 LED입니다. 릴레이 모듈과 LED 모두 LOW에서 켜지므로(active low) 값을 반전합니다. HIGH에서 켜지는 릴레이 모듈이면 스케치의 activeLow 첫 값을 false로 바꿉니다.
- all=1·all=0(모두 켜기·끄기)도 받고 상태를 한 번 보냅니다. 채널 키가 있는 장치의 규칙 명령으로, 버튼 제어기의 'all'이 이 명령 하나를 보냅니다.
