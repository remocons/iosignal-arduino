# iris 버튼 제어기

iris 보드의 버튼 2개로 다른 장치(4채널 릴레이, 스위치, 전등)를 제어하고, LED 4개에 대상의 채널 상태를 보여 줍니다. 대상과 버튼 동작은 보드 설정입니다.

## 준비물

- 보드: iris 보드 (ESP32-C3)
- 네트워크: Wi-Fi 2.4GHz 공유기
- 앱: https://remocon.kr (Iris Button Control 카드의 b1, b2), 대상 장치
- 연동: esp8266-relay4ch

## 배선

| 보드 핀 | 연결 | 비고 |
| --- | --- | --- |
| GPIO1 | 버튼 1 (보드 설정 b1) | 내부 풀업 |
| GPIO2 | 버튼 2 (보드 설정 b2) | 내부 풀업 |
| GPIO4 | WS2812 4개: 대상의 처음 4채널(r1~r4, s1~s4) | 보드에 내장 |
| GPIO8 | 상태 LED: 대상 상태를 알면 켜짐 | active low |

## 사용 순서

1. 스케치를 올리고 USB로 연결해 https://arduino.iosignal.net/wifi/ 에서 Wi-Fi를 넣습니다. 같은 페이지의 스케치 설정 target에 제어할 장치의 CID를 넣습니다.
2. b1, b2를 비워 두면 대상이 3채널 이상일 때 버튼 1은 모두 켜기, 버튼 2는 모두 끄기, 2채널이면 채널 1·2 토글입니다.
3. 버튼마다 하는 일은 보드 설정입니다. 비워 두면 기본 동작이고, 'r1'(릴레이 1 토글), 'r2=1'(켜기), 'all'·'all=0', 'lamp1:toggle'(다른 장치), '#lab:s2'(그룹 채널)처럼 넣습니다. remocon pub "<제어기 cid>@" "b2=r3" 로도 바꾸고, 'b2'만 보내면 그 버튼을 누른 것과 같습니다. 형식은 IOSignal 라이브러리의 IOSignalBinding.h 맨 위에 있습니다.
4. 대상 상태를 받으면 상태 LED가 켜지고, LED 4개가 대상의 채널 상태를 따라갑니다.

## 시그널 절차

| 보내는 쪽 | 받는 쪽 | 태그 | 값 | 설명 |
| --- | --- | --- | --- | --- |
| 장치 | 서버 | `@$name` | `Iris Button Control:HOME` | 이름과 분류(첫 : 뒤)입니다. 서버에 보관됩니다. 분류는 앱이 장치를 묶어 보여 주는 탭 이름입니다. 이름과 분류 모두 보드 설정 name(이름:분류)으로 바꿉니다(바꾸면 바로 다시 보냄). 분류가 없으면 앱의 미분류 탭에 나옵니다. |
| 장치 | 서버 | `@$ui` | `b1,b2` | 버튼 목록입니다. 앱은 누른 버튼 이름을 그대로 명령으로 보냅니다. 서버에 보관됩니다. |
| 장치 | 서버 | `<대상>@$state` | `구독` | 대상과 설정이 이름 붙인 장치마다 구독합니다. 토글은 마지막 상태의 반대를 보냅니다. |
| 장치 | 대상 | `<대상>@` | `r1=1` | all은 all=1/all=0 명령 하나로 보냅니다. 상태를 받기 전에는 토글을 보내지 않습니다. |
| 앱 | 장치 | `<cid>@` | `b1 / b2=r3 / target=?k3vd` | 누르기, 버튼 설정 바꾸기, 대상 바꾸기. 처리 뒤 상태로 답합니다. |
| 장치 | 서버 | `@$state` | `target=?k3vd;link=1;b1=;b2=r3` | link는 대상 상태를 알고 있는지입니다. 잘못된 설정은 ?로 보입니다. |

## 참고

- 2026-11-13 iris 보드에서 확인: 가상 4채널 릴레이를 대상으로 기본 동작(모두 켜기·끄기), b1을 다른 대상의 r4로 바꾸기, 대상 바꾸기를 원격 누르기로 확인했습니다.
- 작은 ESP32-C3 보드는 송신 출력을 8.5 dBm으로 낮추고 Wi-Fi 절전을 끕니다(iris 예제 공통).

## 컴파일

arduino-cli compile --fqbn esp32:esp32:esp32c3 examples/iris-button-controller
