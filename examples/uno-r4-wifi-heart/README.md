# UNO R4 WiFi 하트

UNO R4 WiFi의 LED 매트릭스에 하트를 켜고 끕니다. D12 버튼은 bayo.tv 재생 신호도 보냅니다.

## 준비물

- 보드: Arduino UNO R4 WiFi
- 네트워크: Wi-Fi 2.4GHz 공유기
- 앱: https://remocon.kr 또는 IOSignal Desktop 장치 제어 화면
- 연동: bayo.tv: 버튼을 누르면 #screen playToggle을 받습니다

## 배선

| 보드 핀 | 연결 | 비고 |
| --- | --- | --- |
| D12 | 푸시 버튼, 다른 쪽은 GND | 내부 풀업 |
| 내장 | LED 매트릭스와 LED_BUILTIN | 배선 불필요 |

## 사용 순서

1. 스케치의 WiFi 이름과 비밀번호를 실제 값으로 바꿉니다.
2. 스케치를 업로드합니다. 켜지면 하트가 보입니다.
3. 같은 공유기에 연결한 브라우저로 https://remocon.kr 을 엽니다.
4. UnoR4-WiFi 카드의 버튼을 누르고 D12 버튼도 눌러 봅니다.

## 시그널 절차

| 보내는 쪽 | 받는 쪽 | 태그 | 값 | 설명 |
| --- | --- | --- | --- | --- |
| 장치 | 서버 | `#search` | `구독` | 앱의 검색 요청을 받도록 구독합니다. |
| 장치 | 서버 | `@$name` | `UnoR4-WiFi:HOME` | 이름과 분류(첫 : 뒤)입니다. 서버에 보관됩니다. |
| 장치 | 서버 | `@$ui` | `t=light.1` | 공식 타입 light.1입니다(확장형: 첫 키가 t). 앱이 그 타입의 화면을 그립니다. 서버에 보관됩니다. |
| 장치 | 서버 | `@$state` | `on=1` | 현재 상태입니다. 서버에 보관됩니다. |
| 장치 | 앱 | `#notify` | `<cid>` | 접속했음을 알립니다. |
| 앱 | 장치 | `#search` |  | 앱이 시작할 때, 1초 뒤, 이후 15초마다 보냅니다. |
| 장치 | 앱 | `#notify` | `<cid>` | 검색에 자기 CID로 답합니다. |
| 앱 | 서버 | `<cid>@$name, $ui, $state` | `구독` | 보관된 이름, 버튼(타입), 상태를 바로 받아 카드를 만듭니다. |
| 앱 | 장치 | `<cid>@` | `toggle` | 버튼을 누르면 이름 그대로 명령이 갑니다. 장치가 받는 태그는 @입니다. |
| 장치 | 앱 | `@$state` | `on=0` | 명령을 처리한 뒤 상태를 보냅니다. 앱의 대기 표시가 풀립니다. |
| 서버 | 앱 | `<cid>@$state` | `close` | 장치가 끊기면 서버가 보내고 카드가 사라집니다. |
| 장치 | bayo.tv | `#screen` | `playToggle` | D12 버튼을 누르면 보냅니다. |

## 참고

- 시작 상태가 켜짐이므로 처음 상태는 on=1입니다.

## 컴파일

```sh
arduino-cli compile --fqbn arduino:renesas_uno:unor4wifi examples/uno-r4-wifi-heart
```
