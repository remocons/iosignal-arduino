# D1 mini LED와 버튼

ESP8266 D1 mini의 내장 LED를 웹앱과 버튼으로 켜고 끕니다. 일반 장치의 기본 형태를 보여 줍니다.

## 준비물

- 보드: ESP8266 D1 mini
- 네트워크: Wi-Fi 2.4GHz 공유기
- 앱: https://remocon.kr 또는 IOSignal Desktop 장치 제어 화면

## 배선

| 보드 핀 | 연결 | 비고 |
| --- | --- | --- |
| GPIO14 (D5) | 푸시 버튼, 다른 쪽은 GND | 내부 풀업 |
| GPIO2 (D4) | 내장 LED | active low, 배선 불필요 |

## 사용 순서

1. Wi-Fi는 업로드한 뒤 USB로 연결해 https://arduino.iosignal.net/wifi/ (보드 설정)에서 넣습니다(데스크톱 Chrome·Edge, 보드가 저장). 같은 페이지에서 다른 IOSignal 서버(호스트:포트)와 장치 키도 넣을 수 있습니다. 스케치의 Wi-Fi 값에 실제 값을 쓰면 그 값이 부팅할 때마다 우선합니다.
2. 스케치를 업로드합니다.
3. 같은 공유기에 연결한 브라우저로 https://remocon.kr 을 엽니다.
4. D1-mini 카드의 버튼을 누르고 D5 버튼도 눌러 봅니다.

## 시그널 절차

| 보내는 쪽 | 받는 쪽 | 태그 | 값 | 설명 |
| --- | --- | --- | --- | --- |
| 장치 | 서버 | `#search` | `구독` | 앱의 검색 요청을 받도록 구독합니다. |
| 장치 | 서버 | `@$name` | `D1-mini:HOME` | 이름과 분류(첫 : 뒤)입니다. 서버에 보관됩니다. 분류는 앱이 장치를 묶어 보여 주는 탭 이름입니다. 이름과 분류 모두 보드 설정 name(이름:분류)으로 바꿉니다(바꾸면 바로 다시 보냄). 분류가 없으면 앱의 미분류 탭에 나옵니다. |
| 장치 | 서버 | `@$ui` | `t=light.1` | 공식 타입 light.1입니다(확장형: 첫 키가 t). 앱이 그 타입의 화면을 그립니다. 서버에 보관됩니다. |
| 장치 | 서버 | `@$state` | `on=0` | 현재 상태입니다. 서버에 보관됩니다. |
| 장치 | 앱 | `#notify` | `<cid>` | 접속했음을 알립니다. |
| 앱 | 장치 | `#search` |  | 앱이 시작할 때, 1초 뒤, 이후 15초마다 보냅니다. |
| 장치 | 앱 | `#notify` | `<cid>` | 검색에 자기 CID로 답합니다. |
| 앱 | 서버 | `<cid>@$name, $ui, $state` | `구독` | 보관된 이름, 버튼(타입), 상태를 바로 받아 카드를 만듭니다. |
| 앱 | 장치 | `<cid>@` | `toggle` | 버튼을 누르면 이름 그대로 명령이 갑니다. 장치가 받는 태그는 @입니다. |
| 장치 | 앱 | `@$state` | `on=1` | 명령을 처리한 뒤 상태를 보냅니다. 앱의 대기 표시가 풀립니다. |
| 서버 | 앱 | `<cid>@$state` | `close` | 장치가 끊기면 서버가 보내고 카드가 사라집니다. |

## 참고

- 내장 LED는 LOW일 때 켜지므로 상태 값과 핀 값이 반대입니다.

## 컴파일

```sh
arduino-cli compile --fqbn esp8266:esp8266:d1_mini examples/d1-mini-led-button
```
